# Project 10: Compiler Part 1
This project consists of a syntax token analyzer, written in javascript, that parses the Jack language into tokens. 
The descriptions for each token is expressed as an element in a set of xml files for visibility; but once plugged in with part 2 of the compiler, they are fed directly into the parser for translation into machine code (Hack).
