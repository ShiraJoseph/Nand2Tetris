# Project 9: High-Level Language

A project to design and write a program using Nand2Tetris's high-level programming language, Jack.

Contained is a **Graphic Calculator** written in Jack.
It can draw lines using various equation formats and values chosen by the user.
Inputs can contain negative numbers and fractions, and the values are converted to points on a cartesian plane.
Points are then drawn as coordinates on the Hack computer screen.

Custom classes include a font designed specifically to make better use of screen space, 
graphics for ticks and arrows on the screen, string manipulation, fraction math, and negative integer math.
Constants for certain values (like the width of the screen) are stored globally for better memory management.

Unit tests are included in Test.jack.
